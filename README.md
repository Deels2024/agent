# Агент покупок

Полный full-stack проект сервиса, который помогает покупателю найти товар по названию, фотографии или штрих-коду, сравнить предложения маркетплейсов и небольших магазинов, увидеть итоговую цену и выбрать надёжного продавца.

Рабочая версия: https://buyer-agent-prototype.deels.chatgpt.site

## Что входит в репозиторий

- клиентский веб-сервис с пятью разделами: поиск, цены, покупки, помощь и профиль;
- рабочая страница поиска с сортировкой до 10 предложений;
- распознавание товара по фотографии через OpenAI Responses API;
- поиск по названию и штрих-коду;
- адаптеры Wildberries, Ozon и Яндекс Маркета;
- предложения небольших продавцов и сценарий безопасной сделки;
- прозрачная карточка предложения: товар, доставка, итог к оплате, гарантия, возврат и рейтинг;
- история поисков и предложений в Cloudflare D1;
- центр интеграций и веб-интерфейс контроля backend;
- полный кликабельный дизайн из 40 экранов покупателя, продавца и администратора;
- адаптивная вёрстка для компьютера, планшета и телефона;
- серверные API, миграции базы, тесты и конфигурация production-сборки.

## Основные страницы

| Адрес | Назначение |
| --- | --- |
| `/` | Основной сервис покупателя |
| `/live-search` | Рабочий поиск и сравнение предложений |
| `/prototype` | Все 40 экранов дизайна |
| `/backend` | Состояние интеграций и история запросов |

## API

| Метод и путь | Назначение |
| --- | --- |
| `POST /api/search` | Поиск по названию, штрих-коду или распознанной модели |
| `POST /api/recognize` | Распознавание товара по фотографии |
| `GET /api/history` | Последние поиски и найденные предложения |
| `GET /api/health` | Состояние backend и доступные возможности |
| `GET /api/marketplaces/status` | Готовность интеграций и отсутствующие настройки |

Пример запроса:

```bash
curl -X POST http://localhost:3000/api/search \
  -H 'Content-Type: application/json' \
  -d '{"query":"Apple AirPods Pro 2 USB-C","mode":"text","limit":10}'
```

Без ключей маркетплейсов поиск запускается в честном демонстрационном режиме. Демо-предложения всегда помечаются и не выдаются за актуальные цены.

## Технологии

- TypeScript, React 19 и Next.js 16;
- Vinext и Vite;
- Cloudflare Workers и D1;
- Drizzle ORM;
- OpenAI Responses API для поиска по фотографии;
- официальные seller API маркетплейсов.

## Быстрый запуск

Требуется Node.js `22.13` или новее.

```bash
git clone https://github.com/Deels2024/agent.git
cd agent
npm ci
cp .env.example .env.local
npm run dev
```

После запуска откройте адрес, который покажет Vite. Поиск по названию доступен и без внешних ключей.

Production-сборка:

```bash
npm run build
npm run start
```

Проверки:

```bash
npm run lint
npm test
```

## Настройка интеграций

Скопируйте `.env.example` в `.env.local` и заполните только нужные переменные:

```dotenv
OPENAI_API_KEY=
OPENAI_VISION_MODEL=gpt-5.4-nano

WB_API_TOKEN=
WB_CLIENT_SECRET=

OZON_CLIENT_ID=
OZON_API_KEY=

YANDEX_MARKET_API_KEY=
YANDEX_MARKET_BUSINESS_ID=
```

Секреты нельзя добавлять в Git, клиентский код или сообщения. В production они задаются как защищённые переменные среды сервера.

### Ограничение официальных API

Подключённые сейчас официальные API предназначены для кабинетов продавцов и показывают товары соответствующих продавцов. Глобальный поиск по всему публичному каталогу Wildberries, Ozon и Яндекс Маркета требует отдельных партнёрских договорённостей с площадками. Неавторизованный scraping в проект намеренно не добавлен.

## База данных

В D1 сохраняются:

- поисковые запросы;
- найденные предложения и цены;
- результаты распознавания фотографий;
- технические события интеграций.

Схема находится в `db/schema.ts`, готовая миграция — в `drizzle/`.

После изменения схемы:

```bash
npm run db:generate
```

При первом обращении backend также безопасно создаёт отсутствующие таблицы через `db/ensure.ts`.

## Что потребуется для коммерческого запуска

1. Получить официальные партнёрские доступы маркетплейсов.
2. Подключить авторизацию покупателей и продавцов.
3. Добавить платёжного партнёра для безопасной сделки.
4. Подключить уведомления о снижении цены.
5. Реализовать KYC продавцов, возвраты, споры и антифрод.
6. Добавить мониторинг, аналитику и резервное копирование.

Проект уже содержит интерфейсы и основные сценарии этих функций, но платёжные и юридически значимые операции должны подключаться только после выбора официальных партнёров.
